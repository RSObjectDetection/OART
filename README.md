# 一、密度项机制
## 1.密度项与正确性的关联
<img width="1651" height="911" alt="密度与正确性的关联关系" src="https://github.com/user-attachments/assets/eaaa27fc-2e05-488a-bf5a-8fd879d704d7" />
图中展示了不同 self-quality 水平下，候选框重叠密度与预测正确性的关系。

横轴 D1–D5 表示在每个 self-quality 区间内，按密度从低到高划分的五个等数量组；纵轴为正确候选框比例，其中 correct 定义为候选框与同图像、同类别 GT 的 IoU ≥ 0.5。
三条曲线分别对应 self-quality 为 [0.4, 0.6)、[0.6, 0.8) 和 [0.8, 1.0] 的候选框。

合成曲线展示了一种假设趋势：在自身质量相近时，候选框重叠密度越高，正确候选框比例越低，提示密度可能提供额外的可靠性线索

## 2.密度项消融实验
<img width="825" height="170" alt="消融密度与冲突项" src="https://github.com/user-attachments/assets/8ec0532a-cc68-4443-bb8f-9dba4a6d8dbd" />

表中比较了 DIOR 10% 标注、关闭 ASCR 设置下，不同可靠性建模方式在各目标密度子集上的检测性能。按照表中示例数值，DCPR 相比 ET 的整体 AP50 提高了 1.2 个百分点，在低、中、高密度子集上分别提高了 0.8、1.1 和 1.6 个百分点，同时优于仅加入密度项或冲突项的配置。该示例呈现了两项联合建模可能带来互补收益、且高密度场景改善更明显的预期趋势。

密度子集：统计每个 GT 在一定邻域内的其他 GT 数量，邻域范围结合目标尺度确定；再将图像内各 GT 的邻居数量取平均，作为图像拥挤分数，据此划分低、中、高三个子集。
