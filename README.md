横轴 D1–D5 表示在每个 self-quality 区间内，按密度从低到高划分的五个等数量组；纵轴为正确候选框比例，其中 correct 定义为候选框与同图像、同类别 GT 的 IoU ≥ 0.5。

# 三、伪标签正确性
<img width="823" height="203" alt="伪标签正确性" src="https://github.com/user-attachments/assets/165231c5-cd5f-4a7d-aafc-2e3c8da8f10b" />

固定同一个教师模型，在 DIOR 验证集上生成候选框。从同一批粗筛后的 pre-NMS 候选框计算两种分数，再用原始置信度执行一次 NMS。完整 DCPR 按论文的高阈值规则确定 \(K_0\)，随后两组分别按各自的分数排序，在 NMS 后的结果中取前 \(K_0\) 个框。预测框与同图、同类别的真值框按 IoU 从高到低做一对一匹配，IoU 达到 0.5 的匹配计为真阳性。表中精度为 \(\mathrm{TP}/K\)。
在实际高阈值对应的保留数量 \(K_0\) 下，完整 DCPR 的伪标签精度为 86.40%，比原始置信度高 2.20 个百分点，说明在伪标签数量相同的条件下，置信度冲突项有助于将更多正确的候选框排到前面。
